    3. MLP

    This report follows the statement's thread: what does a hidden layer buy you? Exercise 1 runs one step of backpropagation by hand. Exercise 2 trains an MLP on a binary dataset that no straight line can separate. Exercise 3 reuses the same network, unchanged, for three classes. Exercise 4 checks whether a second hidden layer helps.

    • Statement: Exercises → 3. MLP (2026.2)
    • How to re-run: from the repository root, python docs/exercises/mlp/code/main.py. It takes about a minute on a laptop CPU. It prints every number quoted below, one labelled line each, and rewrites figures/fig1.png … fig6.png. Two runs give identical output.
    • Code: code/mlp.py (the MLP, written from scratch in NumPy), code/main.py (data, baselines, training, figures) and code/check_backprop.py (a numerical check of Exercise 1). Libraries: numpy and matplotlib. scikit-learn is used only for make_blobs, make_classification, train_test_split, confusion_matrix and the LogisticRegression baselines the statement allows.
    • Seed policy: main.py creates one generator, rng = np.random.default_rng(42), and passes it through Exercises 2 → 3 → 4 in order. Every weight initialisation draws from it. The datasets use random_state=42 exactly as the statement gives them. The one exception is the multi-seed comparison of Exercise 4B, which the statement asks for. There, both architectures are initialised with the same explicit seeds, 42, 43, 44, 45 and 46. Training is full-batch gradient descent with no shuffling, so the initial weights are the only thing a seed changes.
    • Notation: the statement writes \(W^{(1)}, W^{(2)}\), and the lecture writes the same two-layer network as \(W, V\). So \(W^{(1)} \equiv W\), \(W^{(2)} \equiv V\), \(b^{(1)} \equiv b_h\) and \(b^{(2)} \equiv b_y\). Row \(i\) of \(W^{(l)}\) holds the weights of neuron \(i\), so \(z = Wx + b\).

    Design decisions, shared by Exercises 2–4:

    1. One class, MLP(layer_sizes, hidden_activation="tanh", output="sigmoid" | "softmax", rng). The layer sizes are a list argument. output selects the output activation together with its matching loss: sigmoid with binary cross-entropy, or softmax with categorical cross-entropy.
    2. Full-batch gradient descent with a fixed learning rate. The training loss is recorded at every epoch.
    3. Xavier/Glorot-normal initialisation, \(w \sim \mathcal N\!\left(0,\, 2/(n_\text{in}+n_\text{out})\right)\), with zero biases. This scale keeps tanh units out of saturation at the start.
    4. Inputs are standardised with the TRAIN mean and standard deviation. The test set and the plotting grid go through the same transform, never through their own statistics.
    5. The test set is used once, for the final numbers. The hidden width and the learning rate are chosen on a validation split carved out of the training set: 75 % fit, 25 % validation, stratified, random_state=42. The rule is lowest validation cross-entropy.

    Exercise 1

    One step of backpropagation, by hand. The network has 2 inputs, 2 tanh hidden units, 1 tanh output and the loss \(L = (y-\hat y)^2\) with \(N = 1\). Every quantity below is derived symbolically first and then evaluated. Values are rounded to 6 decimals, above the 4 the statement asks for. Each value is computed from the unrounded value before it, so redoing a step from the rounded figures can change the last digit. The script check_backprop.py repeats the arithmetic and checks every gradient against finite differences. It only verifies the hand derivation; the derivation below is the deliverable.

    Given values: \(x = [0.5,\ -0.2]^\top\), \(y = 1.0\), \(W^{(1)} = \begin{bmatrix} 0.3 & -0.1 \\ 0.2 & 0.4 \end{bmatrix}\), \(b^{(1)} = [0.1,\ -0.2]^\top\), \(W^{(2)} = [0.5,\ -0.3]\), \(b^{(2)} = 0.2\), \(\eta = 0.3\), and \(\tanh'(u) = 1-\tanh^2(u)\).

    A — Forward pass

    1. Hidden pre-activations, \(z^{(1)} = W^{(1)}x + b^{(1)}\):

    \[ \begin{aligned} z^{(1)}_1 &= 0.3(0.5) + (-0.1)(-0.2) + 0.1 = 0.15 + 0.02 + 0.1 = \mathbf{0.270000}\\ z^{(1)}_2 &= 0.2(0.5) + 0.4(-0.2) + (-0.2) = 0.10 - 0.08 - 0.2 = \mathbf{-0.180000} \end{aligned} \]

    2. Hidden activations, \(h^{(1)} = \tanh(z^{(1)})\), using \(\tanh(z) = \dfrac{e^{2z}-1}{e^{2z}+1}\):

    \[ \begin{aligned} h^{(1)}_1 &= \tanh(0.27) = \frac{e^{0.54}-1}{e^{0.54}+1} = \frac{1.716007-1}{1.716007+1} = \frac{0.716007}{2.716007} = \mathbf{0.263625}\\ h^{(1)}_2 &= \tanh(-0.18) = \frac{e^{-0.36}-1}{e^{-0.36}+1} = \frac{0.697676-1}{0.697676+1} = \frac{-0.302324}{1.697676} = \mathbf{-0.178081} \end{aligned} \]

    3. Output pre-activation, \(u^{(2)} = W^{(2)}h^{(1)} + b^{(2)}\):

    \[ u^{(2)} = 0.5(0.263625) + (-0.3)(-0.178081) + 0.2 = 0.131812 + 0.053424 + 0.2 = \mathbf{0.385237} \]

    4. Output and loss:

    \[ \hat y = \tanh(0.385237) = \frac{e^{0.770474}-1}{e^{0.770474}+1} = \frac{2.160789-1}{2.160789+1} = \frac{1.160789}{3.160789} = \mathbf{0.367247} \]
    \[ L = (y - \hat y)^2 = (1 - 0.367247)^2 = 0.632753^2 = \mathbf{0.400377} \]

    The output starts far from the target: \(\hat y = 0.3672\) against \(y = 1\).

    B — Backward pass

    Each gradient applies the chain rule to the one before it. The symbolic form comes first, then the numbers.

    1. Output pre-activation, \(\partial L/\partial u^{(2)}\). Start from the loss with respect to the output. From \(L = (y-\hat y)^2\):

    \[ \frac{\partial L}{\partial \hat y} = -2\,(y - \hat y) = -2(0.632753) = \mathbf{-1.265507} \]

    Then apply the tanh derivative: \(\hat y = \tanh(u^{(2)})\), so \(\dfrac{\partial \hat y}{\partial u^{(2)}} = 1-\hat y^{2}\), with \(\hat y^2 = 0.367247^2 = 0.134870\):

    \[ \begin{aligned} \delta^{(2)} \equiv \frac{\partial L}{\partial u^{(2)}} &= \frac{\partial L}{\partial \hat y}\,(1-\hat y^2)\\ &= -1.265507 \times (1 - 0.134870) = -1.265507 \times 0.865130 = \mathbf{-1.094828} \end{aligned} \]

    2. Output layer, \(\partial L/\partial W^{(2)}\) and \(\partial L/\partial b^{(2)}\). \(u^{(2)} = \sum_j W^{(2)}_j h^{(1)}_j + b^{(2)}\), so \(\partial u^{(2)}/\partial W^{(2)}_j = h^{(1)}_j\) and \(\partial u^{(2)}/\partial b^{(2)} = 1\):

    \[ \frac{\partial L}{\partial W^{(2)}} = \delta^{(2)}\, h^{(1)\top} = -1.094828 \times [0.263625,\ -0.178081] = [\mathbf{-0.288624},\ \mathbf{0.194968}] \]
    \[ \frac{\partial L}{\partial b^{(2)}} = \delta^{(2)} = \mathbf{-1.094828} \]

    3. Propagate back, \(\partial L/\partial h^{(1)}\) and \(\partial L/\partial z^{(1)}\). First the hidden activations: \(\partial u^{(2)}/\partial h^{(1)}_j = W^{(2)}_j\), so

    \[ \frac{\partial L}{\partial h^{(1)}} = \delta^{(2)}\, W^{(2)\top} = -1.094828 \times [0.5,\ -0.3] = [\mathbf{-0.547414},\ \mathbf{0.328448}] \]

    Then the hidden pre-activations: \(h^{(1)}_j = \tanh(z^{(1)}_j)\), so \(\partial h^{(1)}_j / \partial z^{(1)}_j = 1-(h^{(1)}_j)^2\). Here \((h^{(1)})^2 = [0.069498,\ 0.031713]\) and \(1-(h^{(1)})^2 = [0.930502,\ 0.968287]\). Element by element:

    \[ \begin{aligned} \delta^{(1)} \equiv \frac{\partial L}{\partial z^{(1)}} &= \frac{\partial L}{\partial h^{(1)}} \odot \left(1-(h^{(1)})^2\right)\\ &= [-0.547414 \times 0.930502,\ \ 0.328448 \times 0.968287] = [\mathbf{-0.509370},\ \mathbf{0.318032}] \end{aligned} \]

    4. Hidden layer, \(\partial L/\partial W^{(1)}\) and \(\partial L/\partial b^{(1)}\). \(z^{(1)}_i = \sum_j W^{(1)}_{ij}x_j + b^{(1)}_i\), so \(\partial z^{(1)}_i / \partial W^{(1)}_{ij} = x_j\) and \(\partial z^{(1)}_i/\partial b^{(1)}_i = 1\). This gives the outer product \(\delta^{(1)} x^\top\):

    \[ \frac{\partial L}{\partial W^{(1)}} = \delta^{(1)} x^\top = \begin{bmatrix} -0.509370(0.5) & -0.509370(-0.2) \\ 0.318032(0.5) & 0.318032(-0.2) \end{bmatrix} = \begin{bmatrix} \mathbf{-0.254685} & \mathbf{0.101874} \\ \mathbf{0.159016} & \mathbf{-0.063606} \end{bmatrix} \]
    \[ \frac{\partial L}{\partial b^{(1)}} = \delta^{(1)} = [\mathbf{-0.509370},\ \mathbf{0.318032}] \]

    Check. check_backprop.py recomputes the gradients with NumPy and compares each of the 9 scalar gradients with a central finite difference \(\big(L(\theta+\epsilon)-L(\theta-\epsilon)\big)/2\epsilon\), \(\epsilon = 10^{-6}\). The largest disagreement is \(8.3 \times 10^{-11}\).

    def forward(W1, b1, W2, b2):
    """Forward pass: z1 -> h1 -> u2 -> y_hat -> L (MSE with N = 1)."""
    z1 = W1 @ x + b1             # hidden pre-activations, shape (2,)
    h1 = np.tanh(z1)             # hidden activations
    u2 = W2 @ h1 + b2            # output pre-activation (scalar)
    y_hat = np.tanh(u2)          # network output
    L = (y - y_hat) ** 2         # squared error of the single sample
    return z1, h1, u2, y_hat, L


def backward(h1, y_hat, W2):
    """Analytic gradients, chained outward from dL/dy_hat."""
    dL_dyhat = -2.0 * (y - y_hat)            # d/dy_hat of (y - y_hat)^2
    dL_du2 = dL_dyhat * (1.0 - y_hat ** 2)   # tanh'(u2) = 1 - tanh(u2)^2
    dL_dW2 = dL_du2 * h1                     # u2 = W2 . h1 + b2
    dL_db2 = dL_du2
    dL_dh1 = dL_du2 * W2                     # each h1_j feeds u2 through W2_j
    dL_dz1 = dL_dh1 * (1.0 - h1 ** 2)        # element-wise tanh'
    dL_dW1 = np.outer(dL_dz1, x)             # z1_i = sum_j W1_ij x_j + b1_i
    dL_db1 = dL_dz1
    return dict(dL_dyhat=dL_dyhat, dL_du2=dL_du2, dL_dW2=dL_dW2, dL_db2=dL_db2,
                dL_dh1=dL_dh1, dL_dz1=dL_dz1, dL_dW1=dL_dW1, dL_db1=dL_db1)

    C — Parameter update

    Gradient descent applies \(\theta \leftarrow \theta - \eta\,\partial L/\partial\theta\) with \(\eta = 0.3\). The four update rules cover nine scalars: 2 in \(W^{(2)}\), 1 in \(b^{(2)}\), 4 in \(W^{(1)}\) and 2 in \(b^{(1)}\). All nine are listed.

    Output layer:

    \[ \begin{aligned} W^{(2)} &\leftarrow [0.5,\ -0.3] - 0.3\,[-0.288624,\ 0.194968]\\ &= [0.5 + 0.086587,\ -0.3 - 0.058490] = [\mathbf{0.586587},\ \mathbf{-0.358490}]\\[4pt] b^{(2)} &\leftarrow 0.2 - 0.3\,(-1.094828) = 0.2 + 0.328448 = \mathbf{0.528448} \end{aligned} \]

    Hidden layer:

    \[ \begin{aligned} W^{(1)} &\leftarrow \begin{bmatrix} 0.3 & -0.1 \\ 0.2 & 0.4 \end{bmatrix} - 0.3\begin{bmatrix} -0.254685 & 0.101874 \\ 0.159016 & -0.063606 \end{bmatrix}\\[4pt] &= \begin{bmatrix} 0.3 + 0.076405 & -0.1 - 0.030562 \\ 0.2 - 0.047705 & 0.4 + 0.019082 \end{bmatrix} = \begin{bmatrix} \mathbf{0.376405} & \mathbf{-0.130562} \\ \mathbf{0.152295} & \mathbf{0.419082} \end{bmatrix}\\[6pt] b^{(1)} &\leftarrow [0.1,\ -0.2] - 0.3\,[-0.509370,\ 0.318032]\\ &= [0.1 + 0.152811,\ -0.2 - 0.095410] = [\mathbf{0.252811},\ \mathbf{-0.295410}] \end{aligned} \]

    Does the loss go up or down? Down. A second forward pass with the updated parameters proves it:

    \[ \begin{aligned} z^{(1)}_1 &= 0.376405(0.5) + (-0.130562)(-0.2) + 0.252811\\ &= 0.188203 + 0.026112 + 0.252811 = 0.467126\\ z^{(1)}_2 &= 0.152295(0.5) + 0.419082(-0.2) - 0.295410\\ &= 0.076148 - 0.083816 - 0.295410 = -0.303079\\ h^{(1)} &= \tanh(z^{(1)}) = [0.435874,\ -0.294127]\\ u^{(2)} &= 0.586587(0.435874) + (-0.358490)(-0.294127) + 0.528448\\ &= 0.255678 + 0.105442 + 0.528448 = 0.889568\\ \hat y &= \tanh(0.889568) = 0.711181, \qquad L = (1 - 0.711181)^2 = 0.288819^2 = \mathbf{0.083417} \end{aligned} \]

    The loss falls from \(0.400377\) to \(0.083417\), a change of \(-0.316960\) (\(-79.17\,\%\)). The reason is that every parameter moved against its own gradient. To first order, \(L(\theta - \eta g) \approx L(\theta) - \eta\,\lVert g\rVert^2\), and \(\lVert g\rVert^2 = 1.785141 > 0\), so a small enough step must lower the loss. The first-order estimate, \(-0.3 \times 1.785141 = -0.535542\), is larger than the true drop because tanh curves the loss surface. A much larger \(\eta\) could overshoot, but \(\eta = 0.3\) does not, as the second pass shows. The individual moves all push \(\hat y\) up toward \(y = 1\):

    • \(b^{(2)}\) rose by \(0.328448\).
    • \(W^{(2)}_1\) rose where \(h^{(1)}_1 > 0\), and \(W^{(2)}_2\) fell where \(h^{(1)}_2 < 0\), so both products \(W^{(2)}_j h^{(1)}_j\) grew.
    • The hidden parameters made \(h^{(1)}_1\) larger (0.2636 → 0.4359) and \(h^{(1)}_2\) more negative (−0.1781 → −0.2941).

    Together, \(u^{(2)}\) goes from 0.3852 to 0.8896.

    def standardizer(X_ref):
    """Return a function that standardises with the mean/std of X_ref (the TRAIN set).

    tanh saturates for |z| >> 1, so inputs of unit scale keep the first layer in
    its responsive range. Test data is transformed with the train statistics,
    never its own.
    """
    mu, sd = X_ref.mean(axis=0), X_ref.std(axis=0)
    return lambda X: (X - mu) / sd


def targets(y, output, n_out):
    """Labels -> target matrix: column vector for sigmoid, one-hot for softmax."""
    return y[:, None].astype(float) if output == "sigmoid" else one_hot(y, n_out)


def select_hyperparameters(X_tr, y_tr, n_in, n_out, output, widths, lrs, epochs, rng):
    """Small grid search on a validation split carved out of the TRAIN set.

    The test set is never used here; it is touched once, by the final model.
    Selection rule: lowest validation loss (the cross-entropy being optimised).
    It varies smoothly, whereas accuracy on a few hundred points ties often.
    """
    X_fit, X_val, y_fit, y_val = train_test_split(
        X_tr, y_tr, test_size=0.25, random_state=42, stratify=y_tr)
    scale = standardizer(X_fit)                       # statistics of the fit part only
    rows = []
    for width in widths:
        for lr in lrs:
            model = MLP([n_in, width, n_out], output=output, rng=rng)
            model.fit(scale(X_fit), targets(y_fit, output, n_out), epochs, lr)
            val_loss = model.loss(model.forward(scale(X_val)), targets(y_val, output, n_out))
            val_acc = np.mean(model.predict(scale(X_val)) == y_val)
            rows.append((width, lr, val_acc, val_loss))
            print(f"    validation  hidden={width:>2}  lr={lr:<4}  "
                  f"val_acc={val_acc:.4f}  val_loss={val_loss:.4f}")
    best = min(rows, key=lambda r: r[3])
    print(f"    selected    hidden={best[0]}  lr={best[1]}  "
          f"({len(X_fit)} fit / {len(X_val)} validation samples)")
    return best[0], best[1]

    C — Implement the MLP

    Implementation. Everything below is NumPy written by hand: activations, losses, forward pass, gradients and update. The forward pass caches every layer's activation, \(A^{(0)} = X\) and \(A^{(l+1)} = f\!\left(A^{(l)}W^{(l)\top} + b^{(l)}\right)\). The backward pass starts from the output delta \(\delta = (\hat Y - Y)/N\) and runs these steps for each layer:

    \[ \frac{\partial L}{\partial W^{(l)}} = \delta^{(l)\top} A^{(l)},\qquad \frac{\partial L}{\partial b^{(l)}} = \textstyle\sum_n \delta^{(l)}_n,\qquad \delta^{(l-1)} = \left(\delta^{(l)} W^{(l)}\right) \odot f'\!\left(A^{(l)}\right). \]

    This is Exercise 1's chain rule vectorised over \(N\) samples and any number of layers.

    Why the output delta is \(\hat y - y\). Take a sigmoid output with binary cross-entropy: \(\hat y = \sigma(u)\) and \(L = -[y\log\hat y + (1-y)\log(1-\hat y)]\). Then

    \[ \frac{\partial L}{\partial \hat y} = -\frac{y}{\hat y} + \frac{1-y}{1-\hat y} = \frac{\hat y - y}{\hat y(1-\hat y)}, \qquad \frac{\partial \hat y}{\partial u} = \sigma(u)\big(1-\sigma(u)\big) = \hat y(1-\hat y), \]

    and multiplying the two gives

    \[ \frac{\partial L}{\partial u} = \frac{\hat y - y}{\hat y(1-\hat y)}\cdot \hat y(1-\hat y) = \hat y - y . \]

    Averaging over the batch adds the factor \(1/N\). Exercise 3B shows that softmax with categorical cross-entropy gives the same expression. That is why backward() has no branch on the task.

def tanh(z):
    return np.tanh(z)


def tanh_prime_from_output(a):
    return 1.0 - a ** 2                    # d/dz tanh(z) = 1 - tanh(z)^2


def relu(z):
    return np.maximum(0.0, z)


def relu_prime_from_output(a):
    return (a > 0).astype(a.dtype)         # 1 where the unit is active, else 0


HIDDEN = {"tanh": (tanh, tanh_prime_from_output),
          "relu": (relu, relu_prime_from_output)}


def sigmoid(u):
    # Numerically stable logistic function: never exponentiates a large positive number.
    out = np.empty_like(u)
    pos = u >= 0
    out[pos] = 1.0 / (1.0 + np.exp(-u[pos]))
    e = np.exp(u[~pos])
    out[~pos] = e / (1.0 + e)
    return out


def softmax(u):
    # Subtracting the row maximum leaves softmax unchanged and avoids overflow.
    e = np.exp(u - u.max(axis=1, keepdims=True))
    return e / e.sum(axis=1, keepdims=True)

    # ---------------------------------------------------------------------------
# Losses, averaged over the N samples. Probabilities are clipped away from 0
# and 1 so that log() is always finite.
# ---------------------------------------------------------------------------
EPS = 1e-12


def binary_cross_entropy(y_hat, Y):
    p = np.clip(y_hat, EPS, 1.0 - EPS)
    return float(-np.mean(Y * np.log(p) + (1.0 - Y) * np.log(1.0 - p)))


def categorical_cross_entropy(y_hat, Y):
    p = np.clip(y_hat, EPS, 1.0)
    return float(-np.mean(np.sum(Y * np.log(p), axis=1)))

    """A multi-layer perceptron written from scratch with NumPy.

One class serves Exercises 2, 3 and 4. Nothing about the architecture is
hard-coded: the layer sizes, the hidden activation and the output head are
constructor arguments.

    output="sigmoid"  ->  1 sigmoid unit  + binary cross-entropy       (Exercise 2)
    output="softmax"  ->  K softmax units + categorical cross-entropy  (Exercises 3, 4)

Both heads are the *canonical* pairing of activation and loss, for which the
gradient of the loss with respect to the output pre-activation is the same
expression, dL/du = (y_hat - y) / N. That is why forward(), backward() and
step() below contain no branch on the task: Exercises 2, 3 and 4 run exactly
the same lines of code.

Conventions
-----------
* Samples are rows: X has shape (N, d). Targets Y have shape (N, K), where
  K = 1 for the sigmoid head and Y is one-hot for the softmax head.
* W[l] has shape (n_out, n_in): row i holds the weights of neuron i, as in
  Exercise 1 (z = W x + b). For a batch of row vectors this is Z = X W^T + b.
* Layer l = 0 .. n_layers-1 maps activation A[l] to A[l+1]; A[0] = X.
"""

import numpy as np


# ---------------------------------------------------------------------------
# Activations and their derivatives. Each derivative is written in terms of the
# activation's OUTPUT a = f(z), which is what the forward pass caches.
# ---------------------------------------------------------------------------
def tanh(z):
    return np.tanh(z)


def tanh_prime_from_output(a):
    return 1.0 - a ** 2                    # d/dz tanh(z) = 1 - tanh(z)^2


def relu(z):
    return np.maximum(0.0, z)


def relu_prime_from_output(a):
    return (a > 0).astype(a.dtype)         # 1 where the unit is active, else 0


HIDDEN = {"tanh": (tanh, tanh_prime_from_output),
          "relu": (relu, relu_prime_from_output)}


def sigmoid(u):
    # Numerically stable logistic function: never exponentiates a large positive number.
    out = np.empty_like(u)
    pos = u >= 0
    out[pos] = 1.0 / (1.0 + np.exp(-u[pos]))
    e = np.exp(u[~pos])
    out[~pos] = e / (1.0 + e)
    return out


def softmax(u):
    # Subtracting the row maximum leaves softmax unchanged and avoids overflow.
    e = np.exp(u - u.max(axis=1, keepdims=True))
    return e / e.sum(axis=1, keepdims=True)


# ---------------------------------------------------------------------------
# Losses, averaged over the N samples. Probabilities are clipped away from 0
# and 1 so that log() is always finite.
# ---------------------------------------------------------------------------
EPS = 1e-12


def binary_cross_entropy(y_hat, Y):
    p = np.clip(y_hat, EPS, 1.0 - EPS)
    return float(-np.mean(Y * np.log(p) + (1.0 - Y) * np.log(1.0 - p)))


def categorical_cross_entropy(y_hat, Y):
    p = np.clip(y_hat, EPS, 1.0)
    return float(-np.mean(np.sum(Y * np.log(p), axis=1)))


# Output head = (output activation, matching loss). With these canonical
# pairings the output delta is always (y_hat - Y) / N  (see backward()).
OUTPUT = {"sigmoid": (sigmoid, binary_cross_entropy),
          "softmax": (softmax, categorical_cross_entropy)}


class MLP:
    def __init__(self, layer_sizes, hidden_activation="tanh", output="sigmoid", rng=None):
        """layer_sizes = [n_inputs, n_hidden_1, ..., n_hidden_k, n_outputs]."""
        if len(layer_sizes) < 3:
            raise ValueError("an MLP needs at least one hidden layer")
        if output == "sigmoid" and layer_sizes[-1] != 1:
            raise ValueError("the sigmoid head has exactly one output unit")
        self.layer_sizes = list(layer_sizes)
        self.n_layers = len(layer_sizes) - 1           # number of weight matrices
        self.act, self.act_prime = HIDDEN[hidden_activation]
        self.out_act, self.loss_fn = OUTPUT[output]
        self.output = output
        rng = np.random.default_rng() if rng is None else rng

        # Xavier/Glorot-normal initialisation: Var(w) = 2 / (n_in + n_out) keeps the
        # variance of the signal roughly constant from layer to layer for tanh.
        # Biases start at zero; the random weights already break the symmetry.
        self.W, self.b = [], []
        for n_in, n_out in zip(self.layer_sizes[:-1], self.layer_sizes[1:]):
            std = np.sqrt(2.0 / (n_in + n_out))
            self.W.append(rng.normal(0.0, std, size=(n_out, n_in)))
            self.b.append(np.zeros(n_out))

    def n_parameters(self):
        """Total number of trainable scalars (weights + biases)."""
        return int(sum(W.size + b.size for W, b in zip(self.W, self.b)))

    def forward(self, X):
        """Forward pass. Caches every layer's activation for backward()."""
        A = [X]                                   # A[0] is the input itself
        for l in range(self.n_layers):
            Z = A[l] @ self.W[l].T + self.b[l]    # pre-activation, shape (N, n_out)
            if l < self.n_layers - 1:
                A.append(self.act(Z))             # hidden layer: tanh (or relu)
            else:
                A.append(self.out_act(Z))         # output layer: sigmoid or softmax
        self._cache = A
        return A[-1]                              # y_hat

    def loss(self, y_hat, Y):
        """BCE or categorical CE, chosen by the `output` constructor argument."""
        return self.loss_fn(y_hat, Y)

    def backward(self, Y):
        """Backward pass. Returns (dW, db): one gradient array per layer.

        Must be called right after forward(X) on the same batch.
        """
        A = self._cache
        N = Y.shape[0]
        dW = [None] * self.n_layers
        db = [None] * self.n_layers

        # Output delta dL/dU for the last layer. For sigmoid+BCE AND for
        # softmax+categorical-CE this is (y_hat - Y) / N  (derived in the report),
        # so the same line serves the binary and the multi-class network.
        delta = (A[-1] - Y) / N

        for l in range(self.n_layers - 1, -1, -1):
            # Z_l = A_l W_l^T + b_l  =>  dL/dW_l = delta^T A_l,  dL/db_l = sum over samples.
            dW[l] = delta.T @ A[l]
            db[l] = delta.sum(axis=0)
            if l > 0:
                # Send the error back through W_l to the previous activation,
                # then through that layer's activation derivative (element-wise).
                delta = (delta @ self.W[l]) * self.act_prime(A[l])
        return dW, db

    def step(self, dW, db, lr):
        """Plain gradient descent on every weight matrix and bias vector."""
        for l in range(self.n_layers):
            self.W[l] -= lr * dW[l]
            self.b[l] -= lr * db[l]

    def fit(self, X, Y, epochs, lr):
        """Full-batch gradient descent. Returns the training loss of every epoch.

        The loss recorded for epoch t is computed on the forward pass of that
        epoch, i.e. just before the epoch's parameter update.
        """
        history = np.empty(epochs)
        for t in range(epochs):
            y_hat = self.forward(X)               # 1. forward pass (caches activations)
            history[t] = self.loss(y_hat, Y)      # 2. record the training loss
            dW, db = self.backward(Y)             # 3. gradients of every layer
            self.step(dW, db, lr)                 # 4. gradient-descent update
        return history

    def predict_proba(self, X):
        return self.forward(X)

    def predict(self, X):
        """Class labels: threshold 0.5 for the sigmoid head, argmax for softmax."""
        p = self.forward(X)
        if self.output == "sigmoid":
            return (p[:, 0] >= 0.5).astype(int)
        return p.argmax(axis=1)


def n_parameters(layer_sizes):
    """Trainable scalars of an MLP with these layer sizes: (n_in + 1) * n_out per layer."""
    return int(sum((a + 1) * b for a, b in zip(layer_sizes[:-1], layer_sizes[1:])))


def one_hot(y, n_classes):
    """Integer labels (N,) -> one-hot matrix (N, n_classes)."""
    Y = np.zeros((y.shape[0], n_classes))
    Y[np.arange(y.shape[0]), y] = 1.0
    return Y


def gradient_check(model, X, Y, eps=1e-6):
    """Compare backward() with central finite differences on EVERY parameter.

    Returns the largest absolute difference between the analytic and the
    numeric gradient. Used in main.py as a unit test of the hand-written
    backward pass, for both output heads. It perturbs one scalar at a time and
    restores it, so the model is left unchanged; it draws no random numbers.
    """
    model.forward(X)
    dW, db = model.backward(Y)
    worst = 0.0
    for P, G in list(zip(model.W, dW)) + list(zip(model.b, db)):
        for idx in np.ndindex(P.shape):
            old = P[idx]
            P[idx] = old + eps
            L_plus = model.loss(model.forward(X), Y)
            P[idx] = old - eps
            L_minus = model.loss(model.forward(X), Y)
            P[idx] = old
            numeric = (L_plus - L_minus) / (2 * eps)
            worst = max(worst, abs(numeric - G[idx]))
    return worst

    D — Analysis

    The shape of the class-1 region (Figure 3). The MLP assigns class 1 to two disconnected regions, one in the lower-left corner and one in the upper-right. Between them runs a band of class 0 along the anti-diagonal. The band's two edges are nearly straight and nearly parallel. Along the diagonal \(x_1 = x_2 = s\), which passes through all three cluster centres, the prediction switches from class 1 to class 0 at \(s = -1.613\) and back to class 1 at \(s = 1.721\). The band is therefore 4.715 units wide, centred on the class-0 cluster, and class 1 covers 56.5 % of the plotted area. On the test set the MLP is right on 94 % of the origin cluster, 93 % of the \((3,3)\) cluster and 88 % of the \((-3,-3)\) cluster. 14 of its 16 errors (×) lie within 0.85 of an edge, where the Gaussian tails overlap. The other two are class-1 tail points, at \((-0.92, -0.32)\) and \((-1.58, 0.11)\), which sit 1.4 and 1.2 units inside the band.

    Why no single straight line can produce it. A line splits the plane into two half-planes, and a half-plane is convex: it contains the whole segment between any two of its points. Class 1 sits at \((-3,-3)\) and \((3,3)\), and the segment between them passes through \((0,0)\), the centre of class 0. A half-plane that holds both class-1 clusters therefore also holds the class-0 cluster. Any line must misclassify at least one entire cluster: either one class-1 cluster lands on the class-0 side, or class 0 lands on the class-1 side. Even the best possible line gives up a quarter of the data, about 75 % accuracy. The MLP gets past this because each tanh unit draws its own line. The output unit combines two roughly parallel lines, "above the upper edge" OR "below the lower edge", and so builds a band, which is not convex.

    Why the baseline lands below 50 %, not at 75 %. Logistic regression maximises likelihood, not accuracy. The two class-1 clusters are mirror images through the origin, so the class-1 mean and the class-0 mean almost coincide: \((0.206, 0.205)\) against \((0.017, 0.055)\) on the training set. Tilting the line toward one class-1 cluster costs as much likelihood on the other as it gains. The optimum is therefore a nearly flat model, with \(\lVert w\rVert \approx 0.07\) and test probabilities between 0.457 and 0.543. Where its boundary falls is decided by sampling noise. The dashed line in Figure 3 is almost vertical, \(x_1 = 0.119 - 0.060\,x_2\). It passes through the middle of the class-0 cluster, so on the test set:

    test cluster points predicted class 1 baseline accuracy
    class 0, origin 100 47 % 53 %
    class 1, \((3,3)\) 42 100 % 100 %
    class 1, \((-3,-3)\) 58 0 % 0 %
    total 200 (53 + 42 + 0) / 200 = 47.5 %

    The baseline cuts class 0 in half and gets one class-1 cluster entirely right and the other entirely wrong. The test split happens to hold more points from the cluster it gets wrong (58 against 42), so the result falls below 50 %. On the training split the same line scores 53.25 %. The failure is geometric: class 1 sits on both sides of class 0, and the MLP's two-edged band in Figure 3 is exactly the shape a single line cannot draw. That moves accuracy from 47.5 % to 92.0 %.

    Derivation of \(\partial L/\partial u\) for softmax + cross-entropy. For one sample with logits \(u \in \mathbb R^K\) and a one-hot target \(y\):

    \[ \hat y_k = \frac{e^{u_k}}{\sum_{m} e^{u_m}}, \qquad L = -\sum_{k} y_k \log \hat y_k . \]

    Step 1, the softmax Jacobian. Write \(S = \sum_m e^{u_m}\) and apply the quotient rule:

    \[ \frac{\partial \hat y_k}{\partial u_j} = \begin{cases} \dfrac{e^{u_k} S - e^{u_k} e^{u_k}}{S^2} = \hat y_k (1-\hat y_k), & j = k\\[10pt] \dfrac{0\cdot S - e^{u_k} e^{u_j}}{S^2} = -\hat y_k \hat y_j, & j \neq k \end{cases} \]

    so that

    \[ \frac{\partial \hat y_k}{\partial u_j} = \hat y_k(\delta_{kj} - \hat y_j), \qquad J = \operatorname{diag}(\hat y) - \hat y \hat y^\top . \]

    Step 2, the loss with respect to the probabilities: \(\dfrac{\partial L}{\partial \hat y_k} = -\dfrac{y_k}{\hat y_k}\).

    Step 3, the chain rule summed over every output \(k\):

    \[ \frac{\partial L}{\partial u_j} = \sum_k \frac{\partial L}{\partial \hat y_k}\frac{\partial \hat y_k}{\partial u_j} = \sum_k \left(-\frac{y_k}{\hat y_k}\right)\hat y_k(\delta_{kj} - \hat y_j) = -y_j + \hat y_j \sum_k y_k = \boxed{\hat y_j - y_j}, \]

    using \(\sum_k y_k = 1\). In vector form, \(\nabla_u L = J^\top \nabla_{\hat y} L = \hat y - y\). Over a batch the mean adds \(1/N\).

    Why it is so simple. The \(1/\hat y_k\) from the logarithm cancels the \(\hat y_k\) factor in the softmax Jacobian, because the log undoes the exponential. The gradient that remains is the prediction error, bounded in \([-1, 1]\). It stays large when a confident prediction is wrong. Compare Exercise 1, MSE with tanh, where \(\partial L/\partial u = -2(y-\hat y)(1-\hat y^2)\) keeps the activation derivative: a saturated, wrong output gets almost no gradient there. Sigmoid with BCE (Exercise 2C) is the \(K = 2\) case of the same result.

The two other pairs each share an edge, and the most-confused pair (0, 1) shares edge C0–C1. C1, the widest cluster in the data with an RMS radius of 2.71, sits on that edge. C1 also touches C2, a class-2 cluster, so it is the cluster wedged between the other two classes. It is the hardest cluster in Figure 5: only 65 % correct, with 10 of its 49 test points called class 0 and 7 called class 2. On paper, class 1 ↔ 2 has two edges against one, but its second edge, C2–C4, involves C4, the tightest cluster (RMS radius 1.81).     Baseline comparison. Logistic regression on the same standardised inputs reaches 66.3 %. The MLP reaches 85.0 %, 18.67 points higher. The baseline's errors fall where the clusters interleave: it confuses class 1 and class 2 57 times (32 + 25), against 15 for the MLP. It is worst on C2 (41 %) and C1 (51 %), and holds class 0 at 80 %. The reason is again convexity. A linear softmax classifier gives each class a convex region, so if both centres of a class are classified correctly, the whole segment between them is too. The segment from C1 to C4, class 1's two centres, passes only 1.49 from the centre of C2 (class 2, RMS radius 2.45). The segment from C2 to C5, class 2's two centres, passes 1.56 from C1 and 1.59 from C4, both class 1. Each class's segment runs through the bulk of the other class's cluster, so a linear model cannot keep both clusters of class 1 and both of class 2. Class 0's segment, C0 to C3, stays at least 2.03 from every other-class centre, which is why the baseline does fine on class 0.

    What the hidden layer adds is non-convex class regions. With 32 tanh units the network can shape each class as a union of two separate blobs, one per cluster. The clusters the baseline sacrifices recover most: C2 goes from 41 % to 80 %, C4 from 65 % to 96 % and C1 from 51 % to 65 %. What is left is overlap the data itself contains.

    C — Analysis

    Result: the second hidden layer does not help on this data. It reaches a lower training loss and the same or slightly lower test accuracy. I explain this from the structure of the data.

    1. The data needs few, simple boundaries. There are 6 roughly Gaussian clusters in 4-D (Exercise 3D). The boundary between two Gaussians is smooth, at most quadratic. One layer of 32 tanh units is enough to wrap each cluster in its own region, and the one-layer network already fixes the clusters the linear model loses. To estimate how much the overlap leaves, I fit one Gaussian per generating cluster on the training points and classify each test point by its most likely cluster. This reference gets the cluster ids, which the networks never see, so it is a ceiling estimate, not a competitor. It reaches 89.33 %. The shallow network is 3.47 points below it and the deep one 3.80. The remaining errors come from overlap: 15–18 % of the points on the three hypercube edges fall past the midpoint, plus 2 flipped test labels. A second layer adds no new information to separate those points.

    2. What depth adds in representation, and what it costs. A second layer composes features: it builds new features out of the first layer's hyperplanes. That can draw very complex regions with few units, but only when the target region is itself a composition, and six blobs are not. The costs are measurable:

    • Size and compute. The parameter count grows 5.1× (259 → 1315), and so does the compute per epoch.
    • Stability. With the same \(\eta = 0.3\), the one-layer loss decreased at every epoch of all six runs. The two-layer loss went up in 292 epochs of the shared-rng run, including the spike of +0.0130 at epoch 1217 that is visible in Figure 6. For seed 43 it went up in 20 epochs, all between epochs 1950 and 1971, which shows as the spike on the thin violet curve near the right edge of Figure 6 (largest single-epoch increase +0.0074, at epoch 1967). Gradient descent is stable only while the curvature of the loss stays below about \(2/\eta\). Chaining two layers' Jacobians makes the surface sharper, so the same step sits closer to that limit for the deeper network. Tuning the deep model's learning rate separately would change the comparison, so it was not done.
    • Speed is not the problem here. The deeper network actually lowers the loss faster: the mean over seeds is 0.416 at epoch 200 against 0.553, and 0.249 at epoch 1000 against 0.312. The difficulty is not optimisation speed but what the extra fitting is spent on.

    3. Training loss and test accuracy tell opposite stories. Measured by final training loss, depth "wins" by 29 %, 0.190 against 0.267. Measured by test accuracy, it loses 0.33 points. The train–test gap widens from 4.5 points (90.40 % → 85.87 %) to 8.0 points (93.48 % → 85.53 %). With 1315 parameters for 1200 training points, the extra capacity goes into carving the overlap zones of this particular training sample, including its 9 flipped labels. That fits noise and does not transfer to new points. A lower training loss is evidence of capacity, not of a better model.

    4. What data would reward depth. Data whose decision regions are compositions, where a deep network reuses intermediate features and a shallow one must enumerate every piece:

    • repeated, self-similar patterns, such as stripes or a checkerboard with \(2^k\) cells along a direction. A single hidden layer needs on the order of one unit per boundary, about \(2^k\) units. A deep network can fold the input onto itself once per layer, a tent map composed \(k\) times, using a few units in each of \(k\) layers (Telgarsky, 2016);
    • spirals with many turns;
    • many clusters per class in a higher dimension;
    • natural signals such as images, audio and text, where edges compose into textures, textures into parts and parts into objects.

    Depth also pays off only with enough data, so that the extra parameters learn structure instead of noise. 1200 points of six smooth blobs offer neither condition, and Figure 6 together with the table shows it: a lower curve and the same test accuracy.
